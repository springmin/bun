### What does this PR do?

`rawExit()` on Linux calls `exit_group` unconditionally and otherwise calls `_exit()`. Some restricted environments (seccomp) can make the syscall unavailable; the child should still exit through `_exit()` rather than failing to terminate.

Use `#if defined(__NR_exit_group)` for the syscall, make the call best-effort, and always fall through to `_exit()`.

Part of #47951. This is a generic hardening change; it is not OHOS-specific.

### How did you verify your code works?

- The existing spawn suite covers the normal Linux path.
- There is no focused test yet: reproducing the fallback needs `exit_group` blocked in the child, which the standard CI cannot do. If maintainers prefer, I can fold this into the OHOS spawn PR (where the sandbox supplies that condition) instead of landing it separately.
