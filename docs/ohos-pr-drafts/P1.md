### What does this PR do?

Part of the focused OHOS series tracked in #47951.

Adds `aarch64-unknown-linux-ohos` as a cross-compile target. This PR is the build-system slice only: `scripts/build/config.ts` (the `ohos` OS, OHOS SDK/sysroot fields), `flags.ts` (the OHOS toolchain flags), `rust.ts` (the target and cargo/linker wiring), `source.ts`, `bun.ts`, `tools.ts`, `stream.ts`, `workarounds.ts`, and the local WebKit/ICU/zstd dependency wiring. No runtime behavior changes; all OHOS code is behind the target, so Linux/macOS/Windows builds are unchanged.

The fork has built this target end-to-end on OHOS aarch64 and runs the full suite on-device. This PR is the first piece of the series because every `cfg(target_env = "ohos")` change depends on it.

### How did you verify your code works?

- `bun scripts/build.ts --os=ohos --arch=aarch64 --ohos-sdk-root=<SDK> --ohos-sysroot=<sysroot> --configure-only` on the OHOS host.
- The fork's native build (`scripts/ohos/build-bun-ohos-native.sh`) links and signs the resulting binary and passes its AOT/trim smoke tests.
- Existing-platform build flags are untouched; the OHOS branches are selected only by `--os=ohos`.
- The cross-build CI lane is a follow-up (P18); it will run the same configure step on Ubuntu + the public OHOS SDK so this PR has a non-device check.
