### What does this PR do?

Adds OHOS (OpenHarmony) handling to AOT image loading. The current loader copies code into anonymous memory at a random address; the OHOS image/metadata path needs the image's own base and protections preserved. The patch keeps the image at its linked base with `MAP_FIXED`, maps the whole image, applies RX/R protections, and clears the instruction cache.

This is a WebKit patch for `oven-sh/WebKit`; the Bun side is only the `WEBKIT_VERSION` bump once this and the suspend/resume patch land. Part of #47951.

### How did you verify your code works?

- OHOS device: AOT executables built by the fork run their compiled code and report the expected line tables and mock metadata.
- The fork's AOT smoke (`bun build --compile --aot`, signed executable) passes on-device.
- Existing AOT tests on the other platforms remain green; the OHOS branch is target-gated.
