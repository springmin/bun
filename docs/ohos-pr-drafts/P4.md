### What does this PR do?

Supersedes #30315. Part of the focused OHOS series tracked in #47951.

`os.cpus()` matched `/proc/cpuinfo` with the literal prefixes `processor\t: ` and `model name\t: `. ARM kernels often use different whitespace and report the SoC only in `Hardware`, so those cores got `model: "unknown"`.

Parse each line at the first `:` and trim both sides. `model name` keeps precedence on every core; `Hardware` fills the cores that have no `model name`; a core with neither stays `"unknown"`. x86 behavior is unchanged.

### How did you verify your code works?

- Six unit tests in `src/runtime/node/node_os.rs`: x86 model name, ARM `Hardware` fallback, model-name precedence, per-core mix, missing model, and a processor index beyond the `/proc/stat` count.
- The parser logic was also run standalone (6/6) on the OHOS host; the in-tree tests run with the Rust suite in CI.
- No JS-visible API change; `os.cpus()` keeps the same shape.
