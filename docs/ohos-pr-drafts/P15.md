### What does this PR do?

Adds OHOS (OpenHarmony) handling to the WTF suspend/resume path. On OHOS, a stopped process does not return from `sigsuspend`, so a suspended JSC thread deadlocks. The patch makes `Semaphore::waitFor(double)` use a bounded `sem_timedwait`, changes the handler's `sigsuspend` loop to a 100 ms `sigtimedwait` driven by the existing `SuspendResumeRequest` state, and waits for `waitFor(0.1)` in `Thread::suspend` so the loop re-sends the request.

This is a WebKit patch for `oven-sh/WebKit`; the Bun side is only the `WEBKIT_VERSION` bump once this and the AOT patch land. Part of #47951.

### How did you verify your code works?

- OHOS device: stop/cont and thread-suspension probes no longer hang; the fork's isolation/atomic tests pass.
- Existing WebKit tests for suspend/resume remain green.
- The patch applies to the WebKit revision pinned by Bun; the exact commit is in the patch header.
